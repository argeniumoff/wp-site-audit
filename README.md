# wp-site-audit

Скрипт для быстрого замера страницы сайта. Открывается прямо в консоли браузера, ничего устанавливать не нужно.

## Как пользоваться
1. Открыть нужную страницу сайта.
2. Открыть консоль (F12, вкладка Console).
3. Вставить содержимое файла [audit.js](audit.js) и нажать Enter.

## Что покажет
- время ответа сервера и время загрузки
- число запросов и вес страницы
- сколько скриптов, стилей и картинок
- WordPress ли это, версия, какие плагины подключены
- какие контейнеры Google Tag Manager на странице
